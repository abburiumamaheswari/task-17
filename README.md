# Task 17: Filtering and Sorting DataFrames

## Internship
Veda Technology – Data Science Internship

## Objective
To learn how to filter rows using conditions and sort DataFrame values in ascending and descending order using Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook / Google Colab

## Programs Implemented

### Filtering
1. Filter students with marks greater than 80.
2. Filter students based on age.
3. Filter students by department.
4. Filter marks within a specific range.
5. Apply multiple AND conditions.
6. Apply OR conditions.

### Sorting
1. Sort marks in ascending order.
2. Sort marks in descending order.
3. Sort students based on age.
4. Sort using multiple columns.
5. Sort student names alphabetically.

### Data Analysis
- Display filtered student records.
- Calculate total filtered students.
- Find average marks.
- Identify highest and lowest marks.

## Key Learnings
- Understanding DataFrame filtering.
- Using Boolean conditions.
- Applying AND and OR operators.
- Sorting records using `sort_values()`.
- Performing basic analysis on filtered data.

## Conclusion
Successfully completed Task 17 by implementing multiple filtering and sorting operations using Pandas DataFrames.
